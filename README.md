# Auberge du Saoz — démonstration de refonte

Prototype statique indépendant, non officiel.

## Pour tester
Ouvrir `index.html` dans un navigateur. Une connexion internet est nécessaire pour les images et polices externes.

## Fonctionnel
- Navigation et menu mobile
- Liens téléphone, email, itinéraire et liens vers le site officiel
- Affichage responsive

## Démonstration seulement
- Aucune réservation ou demande de contact n'est traitée par ce prototype
- Photos d'illustration Unsplash, non officielles
- Textes résumés à valider avant toute publication
- Le bandeau identifie la maquette comme non officielle
